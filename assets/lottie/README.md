# Lottie / Rive animations (optional)

Drop mascot and celebration `.json` (Lottie) files here to enrich the UI.
The lesson-completion screen already ships a self-contained confetti burst
(via the `confetti` package) plus an animated reward chest, so no Lottie
asset is required to run the demo. To swap in a Lottie confetti/mascot
animation, add e.g. `confetti.json` here and render it with
`Lottie.asset('assets/lottie/confetti.json')`.
