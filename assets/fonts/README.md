# Fonts

**Cairo** — the app's UI font, bundled so the Arabic (RTL) interface renders
correctly **offline**. Each weight file (400/600/700/800) covers Arabic plus
basic Latin, so the English words being taught render in the same family.

- License: SIL Open Font License 1.1 — see `OFL.txt`.
- Copyright 2009 The Cairo Project Authors (https://github.com/Gue3bara/Cairo).

The files are the Arabic subset served by Google Fonts. Declared under the
`fonts:` section of `pubspec.yaml` as family `Cairo`.
